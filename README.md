# آموزیار

پلتفرم یادگیری تطبیقی برای دانش‌آموزان متوسطه دوم (بخش نرم‌افزار کاربردی).
آزمون تعیین سطح، تمرین تطبیقی، مرور فاصله‌دار لایتنر، مرکز مطالعه، داشبورد پیشرفت و ۱۳ نشان دستاورد.

## اجرا

فایل `index.html` را با هر مرورگری باز کنید. نصب یا سرور لازم نیست و روی موبایل، تبلت و دسکتاپ کار می‌کند.
داده‌ها فقط روی همان دستگاه (localStorage) ذخیره می‌شوند.

## قبل از ارائه: مشخصات سازنده

در فایل `index.html` خط **5915** را پیدا کنید و مقدارها را پر کنید:

```js
const APP_INFO = { maker: "نام شما", school: "نام مدرسه", phone: "شماره تماس" };
```

فایل را با کدگذاری UTF-8 ذخیره کنید.

## انتشار با GitHub Pages

1. فایل‌ها را در یک مخزن (repository) بارگذاری کنید.
2. در مخزن به **Settings ← Pages** بروید.
3. در بخش Source گزینهٔ **Deploy from a branch** را بزنید، شاخهٔ `main` و پوشهٔ `/ (root)` را انتخاب و ذخیره کنید.
4. بعد از یکی دو دقیقه، آدرس برنامه بالای همان صفحه نمایش داده می‌شود.

## ساختار

- `index.html` — کل برنامه (HTML، CSS و JavaScript در یک فایل)
- `docs/` — راهنمای ارائه به داوران (`judges-guide.pdf` و نسخهٔ HTML با فونت وزیرمتن)

## نکته

فونت وزیرمتن و Chart.js از CDN بارگذاری می‌شوند. بدون اینترنت برنامه با فونت جایگزین و نمودار داخلی کار می‌کند.
دستیار «جغد دانا» یک دستیار قاعده‌مند است، نه هوش مصنوعی مولد.
